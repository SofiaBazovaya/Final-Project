# Образовательный сайт по физике

## Описание

Проект - веб-сайт, созданный с целью популяризации и объяснения физических явлений в доступной форме. Сайт содержит подборку статей по различным темам физики и страницу с рекомендуемой литературой.

Проект разработан в среде **WebStorm** с использованием библиотеки **React** и маршрутизации **React Router**.

## Используемые технологии

* HTML, CSS, JS, React и React Router

## Структура сайта

* **Главная страница** - список доступных тем
* **Страницы со статьями** - материалы по следующим темам:

  * «Почему лёд скользкий?»
  * «Почему небо голубое?»
  * «Чёрная дыра» и др.
* **Страница литературы** - список рекомендуемых источников по физике


## Цель проекта

Создание простого образовательного ресурса для изучения и популяризации физики.
